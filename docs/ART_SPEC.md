# ART_SPEC — 美術與技能特效規格（M0，2026-10-16）

> 所有美術與特效工作的**驗收標準**。風格基礎沿用 `docs/ART_STYLE_BIBLE.md`（陣營設定 §2、KayKit 預渲染 §11）；本檔補上「整體統一」與「技能特效語言」。
> 數值與顏色的**單一來源**是程式裡的設定表（`constants.ts`、`data/vfx/**`）；本檔的色票是設計意圖，實作時落地成具名常數。

## 1. 總原則
1. **像素世界、現代特效**（2026-10-16 02:45 使用者定案，取代原「卡通低多邊形」）：角色、障礙物、地形、背景一律是**像素美術**（FFT 式）；技能特效是**現代風格**的全解析度發光層，疊在像素世界之上。像素規格見 §12。
2. **光源固定在左上**（與單位預渲染一致）：亮面朝左上、陰影落右下。地形側面、障礙物、特效的高光都照這個方向。
3. **明度分層**：地形最暗、單位中間、特效與 UI 最亮。特效不得讓地形或單位比它更搶眼；地形不得出現比單位更亮的大面積高光。
4. **陣營一眼可辨**：任何特效只看形狀與色調（不看位置）就要分得出是獅心還是灰燼。
5. **奇幻，不是科幻**：禁止掃描線、Glitch／RGB 分離、全像六角網格、雷射、資料流、科技 UI 線框等語彙出現在戰場特效上。

## 2. 素材分工
| 類別 | 做法 | 負責 | 備註 |
| :-- | :-- | :-- | :-- |
| 單位 | **3D 轉像素**：KayKit 模型以低解析度渲染 → 限色盤 → 1px 外框 → 精靈表 | Blender 管線＋主代理定規格 | 陣營辨識度另案（M4） |
| 障礙物（柱、樹、岩、冰晶） | 同上，KayKit 道具 3D 轉像素 | Blender 管線＋子代理 | 與單位同相機、同光源、同像素密度 |
| 地形材質（頂面、側面） | 像素化程序烘焙：限色盤、無抗鋸齒、像素格對齊 | 主代理 | 取代 AI 貼圖（M1）；R1 的高度明暗與邊緣遮罩保留，改成像素色階 |
| 背景、天空、遠景、霧 | 像素風，低解析度繪製後整數倍放大 | 主代理 | |
| 技能特效 | 程序化零件庫＋資料驅動編排 | 主代理 | 本檔 §5～§8 |
| UI 圖示 | 程序化向量或 KayKit 圖示 | 之後再議 | M5 |

| 用途 | 獅心騎士團（BLUE） | 灰燼軍團（RED） |
| :-- | :-- | :-- |
| 核心（最亮） | 聖白 `#fffbeb` | 餘燼黃 `#fde68a` |

## 4. 形狀與節奏語言
| 面向 | 獅心騎士團 | 灰燼軍團 |
| :-- | :-- | :-- |
| 基本形 | 圓、正多邊形、放射直線、對稱 | 鋸齒、裂痕、不規則火舌、不對稱 |
| 紋章符號 | 日輪（12 道放射）、獅紋盾、十字劍 | 角骷髏、倒三角符文、斷裂環 |
| 邊緣 | 乾淨、柔和外光暈 | 粗糙、帶殘渣、外圈灰煙 |
| 運動 | 由中心向外均勻展開，緩入緩出，停頓莊重 | 爆發快、衰減慢，有抖動和殘留，向上翻騰 |
| 殘留 | 光點緩慢上飄後淡出 | 灰燼與火星飄落、焦痕停留在地面 |

## 5. 元素 × 陣營特效語彙
元素是遊戲機制（`element`），**不改**；改的是它的外觀。

| 元素 | 陣營 | 核心形狀 | 色階（核心→主→暗） | 次要層 | 運動 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| PHYSICAL | 獅心 | 鋼銀劍弧＋十字星火花 | 白→鋼銀→深藍 | 金色小火花 | 快速一閃，弧線 0.15 s 內完成 |
| PHYSICAL | 灰燼 | 重擊裂紋＋塵土衝擊環 | 骨白→鏽→炭黑 | 碎石、塵煙 | 重、短停頓，塵煙慢散 |
| HOLY | 獅心 | 日輪放射、光柱、羽毛光片 | 聖白→金→暖橙 | 上飄光點 | 均勻擴張，柔光脈動 |
| LIGHTNING | 獅心（聖雷） | 自天而降的金白分叉雷 | 聖白→金→皇家藍 | 地面放射光痕 | 瞬間落下、殘影 2～3 幀 |
| ICE | 獅心 | 冰晶尖刺、霜環 | 白→冰青→深藍 | 冰屑、霜霧 | 迅速凝結、碎裂後散落 |
| ARCANE | 獅心 | 法陣（同心圓＋符文刻度）、星點 | 白→皇家藍→深藍 | 旋轉刻度環 | 平穩旋轉、收束 |
| VOID | 獅心（星界） | 星空裂口、引力環 | 白→靛紫→深藍 | 被吸入的星點 | 向內螺旋收縮 |
| BLOOD | 灰燼 | 血色新月斬、血滴 | 淺緋→緋紅→暗紅 | 地面血跡 | 甩出、滴落、停留 |
| FIRE | 灰燼 | 火舌、熔岩噴發、火球 | 餘燼黃→橙→緋紅 | 灰煙、火星 | 爆發後翻騰上升 |
| POISON | 灰燼（瘴氣） | 膽綠瘴霧團、腐蝕泡 | 黃綠 `#d9f99d`→`#84cc16`→`#365314` | 灰燼混雜 | 緩慢擴散、低伏地面 |
| VOID | 灰燼（深淵） | 黑色裂口、緋紅邊緣、骷髏符文 | 緋紅邊→深紫 `#3b0764`→黑 | 向上飄的黑煙 | 撕裂展開、吞噬 |

## 6. 技能層級規則
| 層級 | 層數 | 時長 | 必要元素 | 禁止 |
| :-- | :-- | :-- | :-- | :-- |
| 普攻 | 1～2 層 | ≤ 0.35 s | 命中閃光＋元素小零件 | 鏡頭震動、全螢幕效果 |
| 主動技 | 2～3 層 | ≤ 0.8 s | 起手（可省）、命中、元素殘留 | 全螢幕閃白 |
| 奧義 | 3～5 層 | 1.0～2.0 s | **起手**（法陣或紋章浮現）→**命中**（主爆發＋衝擊環）→**餘韻**（殘留與飄散）；陣營紋章必須出現一次 | 超過 2 s 的遮擋、連續閃白 |

- 奧義的鏡頭震動與閃光沿用既有系統參數，強度不得高於現在。
- 治療、增益類用「上升、聚合」的運動；傷害類用「下壓、擴散」。

## 7. 特效零件庫（V1 要做的零件）
全部**程序化產生、預先烘焙成貼圖或少量影格**，執行期只做 `drawImage`、`globalAlpha`、`globalCompositeOperation` 與平移縮放旋轉。每個零件以參數產生、以參數為快取鍵。

| 零件 | 參數 | 用途 |
| :-- | :-- | :-- |
| `glow` 柔光圓 | 半徑、色階、衰減曲線 | 所有核心光 |
| `ring` 衝擊環 | 半徑、粗細、色階、鋸齒度（0＝乾淨，1＝灰燼風） | 命中、落地 |
| `slashArc` 斬擊弧 | 弧角、厚度、尾端漸細、色階 | 劍、斧、血月斬 |
| `rays` 放射光 | 道數、長度變化、色階 | 日輪、聖光 |
| `bolt` 分叉雷 | 長度、分叉數、亂數種子 | 聖雷 |
| `flame` 火舌 | 高度、搖曳影格數、色階 | 火、熔岩 |
| `smoke` 煙團 | 大小、色、邊緣粗糙度 | 灰煙、塵土、瘴氣 |
| `shard` 碎片 | 形狀（冰晶、碎石、骨片）、色 | 冰、物理碎屑 |
| `sigil` 法陣／符印 | 紋章種類（日輪、獅盾、角骷髏、倒三角）、半徑、色 | 奧義起手、法陣 |
| `pillar` 光柱 | 寬、高、色階 | 聖光柱、深淵柱 |
| `spark` 火花拖尾 | 長度、色 | 命中火花、火星 |
| `droplet` 液滴 | 大小、色 | 血、毒液 |

## 8. 效能規則
1. 執行期**禁止** `shadowBlur`、每幀建立漸層、每幀 `clip`、每幀組長路徑；這些只能出現在烘焙階段。
2. 每個零件的烘焙結果快取；快取鍵是參數，不含時間。
3. 動畫零件用預渲染影格（同地形 R2 的循環影格做法）。
4. 品質分級：沿用 `RenderQuality` 階層與 `VFX_BUDGET.TIER_EMISSION_RATIOS`；低階層減少粒子數與次要層，**主形狀不得消失**。
5. 驗收：`perf:guard` 通過；VFX 風暴場景的 p99 不得高於改造前。

## 10. 可讀性與節制（業界通則，2026-10-16 補充）
1. **先看明度、再看顏色**：特效轉成灰階後仍要讀得懂（主形狀、方向、範圍）。灰階讀不出來，換顏色也救不了。
2. **形狀、時間、顏色三項檢查**：形狀＝剪影、量感、方向是否一眼可辨；時間＝起手→命中→餘韻的節奏是否清楚；顏色＝是否符合 §3.2 的三色階。
3. **起手預告**：會造成大量傷害的奧義，起手階段就要讓人看出「哪裡要被打」（法陣或紋章先出現在落點）。
4. **加法混合（`lighter`）的素材在黑底上設計**，亮度即透明度；煙、灰、血這類實體物質用一般混合（`source-over`），不要用加法。
5. **節制**：最便宜的特效是不存在的特效。層數、粒子數、覆蓋面積（overdraw）以 §6 為上限，寧可少一層也要讓主形狀清楚。
6. **循環特效必須無縫**，接縫比沒有特效更糟。

## 11. 驗收方式
- 每個零件與技能都要有截圖（零件總表、技能 4 格時間序：起手、命中、餘韻前段、餘韻後段），**並附同一張的灰階版**，用來檢查 §10 第 1 條。
- 截圖放 `tools/ui-e2e/out/`，在 `docs/ART_VFX_PLAN.md` 記下檔名。
- 對照本檔 §1 的五條總原則與 §10 的六條逐條自查，不符合就重做。

## 12. 像素規格（P0 原型確認前為暫定值）
1. **兩層渲染**：世界層（地形、障礙物、單位、地面標記）畫在低解析度離屏畫布，再以**最近鄰、整數倍**放大到螢幕；特效層與 UI 以全解析度畫在其上。
2. **像素密度**：暫定世界層 = 螢幕的 1/3（2560×1440 下約 853×480）。P0 會同時出 1/2 與 1/3 的截圖供選擇。
3. **縮放**：鏡頭縮放只允許讓世界像素維持整數倍的級距，避免像素大小不一；平移時世界座標對齊到世界像素格，不做次像素移動。
4. **色盤**：每個地形 16～24 色，單位每陣營 12～16 色；全部寫在設定表，不在程式裡散落顏色。
5. **外框與光源**：物件 1px 深色外框（用該物件最暗色，不用純黑）；光源維持左上；只在大面積漸層處少量使用抖色（dither）。
6. **特效與像素世界的關係**：特效保持平滑與發光，但顏色取自 §3.2 陣營色盤；地面上的命中痕、焦痕這類「留在世界裡」的殘留，畫在世界層（會被像素化），飛行和發光的部分畫在特效層。
