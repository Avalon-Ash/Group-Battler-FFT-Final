### 本輪額外規則

- **取捨順序**（額度吃緊時）：`U0 → A0a/A0b → A1a/A1b → A2a/A2b/A2c → A3`，其餘可略並在報告列為未完成。**任何時候中斷都要確保工作樹乾淨且最後一個 commit 全綠。**
- **效能預算**：本輪所有圖像素材都必須在「載入／烘焙階段」處理成可直接 `drawImage` 的資源；**執行期不得每幀做 `createPattern`、`createRadialGradient`、`getImageData`、濾鏡、`shadowBlur`**。圖集總大小（`public/assets/**`）本輪上限 **12 MB**；單張圖集 WebP 優先。
- **載入體驗**：素材載入期間（通常 <1 s）維持舊程序化外觀，載入完成後平順切換，不得出現空白單位或空白地形；載入失敗（404/解碼錯誤）要**靜默回退**舊外觀並在 `console.warn` **一次**（非渲染迴圈內）。
- **決定性**：`render-fidelity` 的合成時間環境下，素材載入需在量測前完成（腳本等待 `window.__ASSETS_READY__ === true` 或等價旗標；請在素材 store 提供一個唯讀 ready promise，並在 fidelity/perf 腳本中等待它）。
- **不得改**：`Agent`（A2a 的可選資料欄位 `bodyType?` 除外）、`engine/systems/**` 邏輯、`types.ts` 的既有欄位語意（`WindowDef` 新增可選欄位除外）。
- 停工原則：只有遇到會導致產品功能壞掉、且本文件未涵蓋的情況才停下；其餘自行選擇最低風險、可回退的做法並記錄在報告。
