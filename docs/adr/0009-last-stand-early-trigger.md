# 0009 背水一戰依剩餘地塊與存活人數提早觸發

狀態：已取代（由 0010）
日期：2026-11-02

## 背景

舊版 `engine/systems/ZoneSystem.ts` 只在地圖縮到剛好剩 1 格時才觸發背水一戰；終局前沒有終局規則，僅剩多餘單位擠在少數格上等待塌陷，全坦克 175 場進入終局但僅 129 場到達背水一戰，墜落佔全部死亡的 27%。

## 決定

在 AI 與大逃殺 M7 輪將背水一戰觸發條件改為「安全地塊數 ≤ 存活人數，或存活人數 ≤ 3 且地塊數 ≤ 7」；達成條件時停止繼續縮小地圖、收束其餘地塊，並將全員拉至中心格進入 `FINALE`（套用禁治療、單位重疊與加時規則）。

## 放棄的做法

- 維持舊版僅於地塊數剩餘 1 格時觸發背水一戰的規則。

## 後果

- 200 場實測中背水一戰時長為大逃殺平均 2.9 秒（最長 7.1 秒）、全坦克平均 5.3 秒；全坦克墜落佔死亡由 27% 降至 3.2%（含 M8 混用技能，僅到 M7 時約 23%）。
- 使用者於 2026-11-03 實機遊玩後要求保留地圖一路縮至 1 格的搶位過程，本決定由 `0010`（`docs/adr/0010-last-stand-final-ring-countdown.md`）取代。
