# 0007 畫面驗證：同環境 A/B 與保真基準不得任意重錄

狀態：採用
日期：2026-10-29

## 背景

`tools/ui-e2e/render-fidelity.mjs` 輸出的 `meanAbsDiff` 在兩次獨立執行之間會隨環境與時序漂移（例如 OPT-01 O5a 初次派工因比對兩次執行容差而白停兩輪）。
另一方面，若代理在測試失敗後自行重錄基準圖或放寬閾值，畫面回歸問題會被掩蓋。

## 決定

- 證明不改畫面的重構或常數搬家，一律採用「同環境 A/B」：於同一次執行內切換新舊程式碼，逐像素比對要求 0 差異，不拿兩次獨立執行的保真數值比對。
- 保真基準圖與測試門檻不得任意重錄或放寬。
- 僅在預期畫面變動且任務明確允許重錄時，須先產出並檢查新舊差異圖確認僅預期元素改變，以獨立 commit 提交，並列出其餘維持 0 差異的基準。

## 放棄的做法

- 以兩次獨立執行 `render-fidelity.mjs` 的 `meanAbsDiff` 數值差作為「畫面未改變」的證明。
- 在無明確設計依據或未留存差異證據時直接更新基準圖或調高門檻。

## 後果

- OPT-01 O5b～O5d 三輪大型參數具名化皆透過同環境 A/B 0 像素差異證明行為未變，且歷次合法重錄均保留獨立 commit 與差異證據。
- 驗證無視覺改動之重構時須在同一次執行中安排對照切換腳本。
