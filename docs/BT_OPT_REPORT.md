## 2. 核心改動內容與設計理由

### 2.1 常數 SSOT 擴充（BT1）
- **改動**：
  - 在 `constants/combat.ts` 的 `COMBAT_PARAM` 新增：
    - `AI_HEAL_HP_THRESHOLD: 0.95`（治療觸發門檻：友軍血量低於 95% 才視為有效受損目標）。
    - `AI_SELF_BUFF_ENGAGE_DIST: 3`（短效自身／團隊增益施放門檻：自身受損或最近敵軍距離 <= 3 格接戰範圍才觸發）。
  - 同步更新 `tests/constants-snapshot.json`，確保由 `tests/ConstantsBarrel.test.ts` 守門無違規。
- **理由**：將 AI 決策閾值統一收納至戰鬥常數 SSOT，禁止在決策邏輯中寫入魔法數字。

### 2.2 目標選擇與行為樹決策修正（BT2 ＋ 審查修正）
- **改動檔案**：`engine/ai/TargetingSystem.ts`、`engine/ai/BTRegistry.ts`、`engine/systems/combat/CastingEngine.ts`
- **關鍵改動**：
  1. **防止主目標友軍殘留**：
     - `BTConditions.HasTarget` 增加檢查：當 `a.target.team === a.team` 時一律視為無效目標，自動嘗試還原 `_savedCombatTarget`，若仍為友軍或失效則呼叫 `engine.updateTarget(a)` 重新索敵。
     - `BTActions.FindOptimalTarget`：當選中友軍輔助目標時，若目標不在射程內，僅將導航座標寫入 `a.targetHex`，絕不將 `a.target` 覆寫為友軍；若選中目標失敗，自動還原敵軍戰鬥目標並清除 `a.targetHex`。
     - 在 `ChaseTarget`、`Wait`、`Idle`、`EscapeWarning`、`Reposition` 等節點統一調用 `restoreCombatTarget(a, engine)`，確保非輔助施法時段 `a.target` 永不為友軍。
     - 在 `CastingEngine.resetCaster` 中（施法完成或中斷統一出口），若 `a.target && a.target.team === a.team` 則設置 `a.forceAiUpdate = true`，使施法者在結束友軍施法的當幀立即觸發 AI 重新索敵（移除原放於純幾何查詢 `TargetingSystem.getImpactArea` 的副作用）。
  2. **PBAOE 敵軍檢查、追擊距離與非對敵技能不阻塞下層技能**：
     - `calculateOptimalTarget` 對敵方 PBAOE 技能（`range === 0 && type === 'AOE'` 且 `isHostileSkill(skill)`）檢查半徑內是否存在有效敵軍；若無敵軍則回傳 `targetHex: null`。
     - `BTActions.ChaseTarget`：當 `idx < 2`（`Ultimate` 或 `Active` 槽位）的 `Smart Cast` 未命中條件時：
       - 若該技能為**非對敵技能**（治療／友軍增益／自身增益，`!isHostileSkill(skill)`），直接回傳 `NodeState.FAILURE`，讓行為樹立即嘗試下一槽位技能（如普攻 `Slot 2`），防止輔助因 `sr_a1`／`sr_a5`／`sb_a1` 滿血不施放卻在 `ChaseTarget(1)` 回傳 `SUCCESS` 而原地凍結不普攻，或因 `sr_a3`（`aoeRadius: 2`）衝入近戰距離。
       - 若該技能為對敵技能但無需移動（`state === NodeState.SUCCESS` 或被定身 `!CanMove`），於 `idx < 2` 時同樣回傳 `NodeState.FAILURE` 交給下一槽位技能出手。
       - 當 `skill.range === 0` 需要追擊時，對敵 PBAOE 採 `Math.max(1, skill.aoeRadius || 1)`，避免要求尋路踏入敵方佔據格。
  3. **友軍治療目標與自殘保護**：
     - 單體純治療與 HOT 技能在篩選目標時，嚴格略過血量 `>= 95%` 的健康隊友；當技能帶有 `SELF_DAMAGE`（如 `sr_a1` 生命轉移、`sr_a5` 黑暗犧牲）時，強制排除施法者自身。
     - 純群體治療／HOT PBAOE（含 `sr_a3` 治療圖騰、`sb_u2` 復活之光、`sb_u5` 寧靜之雨、`sr_u2` 鮮血契約）只有在範圍內至少有一名隊友血量 `< 95%` 時才回傳腳下格，否則回傳 `targetHex: null`。
  4. **短效戰鬥增益／護盾施放時機**：
     - 自身／團隊短效增益（`range === 0 && power <= 0` 且具護盾／加速／免死／反傷／吸血）必須滿足「自身或隊友受損（`< 95% HP`）」或「最近敵方有效目標距離 `<= 3 格`」時才回傳腳下格，杜絕開場在出生點空開增益。
