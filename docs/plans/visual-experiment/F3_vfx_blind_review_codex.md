## 重複問題前三名

以**技能數**計，同招出現多格只算一次。

1. **10/10 起手都用施法者身上的同心圓環。** 例如 `tb_a1`、`wb_a1` 的 3 格，以及 `rb_u1` 的 23 格。縮回戰場尺寸後，五個職業起手最先讀到的都是同一種環。
2. **7/10 在目標原本可見的臉部疊出白閃或發光柱。** 戰士奧義 46 格、遊俠兩招 47／17 格、法師兩招 31／28 格、輔助兩招 31／17 格。這七招在第 0 格都還能看見目標的臉。
3. **6/10 用金黃主導至少一段主要效果。** 坦克兩招 31／10 格、戰士兩招 46／10 格、輔助兩招 31／17 格。在這些格裡，辨認藍方主要靠血條或底座。

## 優先順序

1. **`sb_a1`**：全畫面看，直達畫面上緣的光柱比同職業奧義更搶眼。改掉柱身，可以同時恢復受術者辨識與普技、奧義的份量差。

**阻礙**：十張圖均可分段辨讀。森林樹冠在第 0 格就遮住多數目標的軀幹，坦克兩招與戰士普技的敵方尤其難辨；身體辨識以施放前仍可見的部位為準。`rb_u1` 等長條只到第 59 格，末格仍亮的效果只能判到該格。陣營判讀限於藍方是否符合冷色規格，樣本沒有紅方對照。
