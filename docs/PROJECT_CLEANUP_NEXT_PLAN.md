## 下一輪：A3-F01，死亡中斷（P1／D3）

目前四次受控死亡觀測皆無 CAST_BREAK，死亡後仍派發 5 個序列動作，傷害為 0。根因在 CastingEngine 的死亡分支只 reset、沒有發送取消事件。

已決定的修法：死亡且仍在有效非 BASIC 詠唱時，在 reset 前送一次 pooled CAST_BREAK，沿用既有 VisualSystem 取消鏈。死亡分支不受中斷冷卻節流；不增加死亡冷卻懲罰。閒置／已完成施法死亡不送此事件，因此保留已射出的投射物。

直接依賴：GameEventPool 現在未 hydrate／release `hexes`。新死亡中斷事件需攜帶 AOE 預警範圍，因此只補該欄位的保存與釋放，避免資料遺失或池重用殘留；不全面重構事件池。

產品修改只限 CastingEngine、GameEventPool；配套一份新回歸測試、Core 中事件池測試、一份報告。精確演算法、測試與命令見 `docs/PROJECT_CLEANUP_F01_AGENT_PROMPT.md`。

驗收：四個死亡案例都有中斷、死亡後派發 0、傷害 0；正常施法、暈眩中斷、重開、AI 重建、空中投射物對照維持。lint/test/build、runtime smoke、perf guard 均取得真實結果；不可重錄基準。若護欄失敗，本輪交回未完成，由主代理判讀。
