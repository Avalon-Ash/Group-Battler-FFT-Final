## 3. 未歸零項目說明（Protected File Invariants）

## 5. 視覺多樣性審查與觀察清單（規格合格但造型偏單調/相似者）

經檢視 `after/blue.png` 與 `after/red.png` 兩張 50 招 5 格序列表，以下技能雖已嚴格符合 C1～C8 數學規格，但在純視覺表現上仍有可優化之處（僅列出供主代理與美術設計參考，未改動）：

1. **`STORM` 原型落點節奏雷同**:
   - `rb_u5`（劇毒箭雨）、`rr_u3`（煉獄火雨）、`mr_u5`（靈魂爆燃）均為在目標區域隨機撒落 8 次落點。雖然各技能的粒子種類（箭矢/火球/魂爆）不同，但落點節奏與散佈模式極為相似，未來可考慮加入不規則落點間隔或交錯群聚。
2. **`BEAM_SNIPE` 藍方戰士與法師**:
